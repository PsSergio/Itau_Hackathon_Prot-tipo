# Radar de Caixa — Assistente Transacional Itaú (Daily Banking)

Projeto desenvolvido para o **Inovacamp 2026**, hackathon promovido pela **Poli Jr.** em parceria com o **Itaú Unibanco**.

---

## 🎯 Proposta do Hackathon

O objetivo do desafio foi desenvolver um **Assistente Transacional** multicanal e multimodal para a vertical de *Daily Banking* do Itaú. A solução visa antecipar necessidades, simplificar a complexidade financeira e executar ações proativas para resolver atritos diários — com foco principal em prever descompassos de fluxo de caixa e evitar a entrada silenciosa do cliente no crédito rotativo e no cheque especial antes do fechamento da fatura.
